Program ini digunakan untuk mengelompokkan nilai ujian mahasiswa menjadi LULUS dan REMEDI. Nilai 65–100 masuk ke LULUS, sedangkan nilai di bawah 65 masuk ke REMEDI. Program meminta pengguna memasukkan minimal 5 nilai dan bisa berhenti dengan mengetik “selesai”. Selain itu, ada fitur untuk mengecek input yang salah dan menghapus nilai jika terjadi kesalahan. Setelah selesai, program akan menampilkan seluruh nilai, nilai LULUS, dan nilai REMEDI.
